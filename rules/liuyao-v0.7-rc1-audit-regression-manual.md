## 二、EV 证据绑定审计总规

凡登记“已执行”，必须绑定 EV 编号。EV 编号必须指向同一次输出中已经实际出现过的判断句、关系句或病药句。审计行必须回引该 EV 的关键词。找不到可回引文字，不得登记已执行，只能写未执行 / 未触发 / 回退。


## 四、药证复核清单

用于判断 Y1 是否存在、是否到 B1、是否落验。不是独立主裁闸，不得越过 F5 病药四问。

药证状态三档：有效药证（能到 B1 且能落现实承接或落验，不被强反证压倒）；弱药候选（有象，只能弱接触 / 只落承接 / 力量不足 / 路径不闭合）；未命中（无 Y1，或被空破伏合绊克泄阻断，或与 B1 无作用）。

有效药证项数：0 项（Y1 不成立，不干扰主裁）；1 项（记录候选，不得写“全无药”）；2 项（强复核，若仍判高危或不成须说明 Y1 为何不能落验）；≥3 项（回退 F5 重答病药四问）。

特殊闭环药证：现实医护承接闭环、时辰兑现链；仅命中特殊组合单项不触发闭环。缺时辰者：时辰类 Y1 不计有效药证，非时辰 Y1 正常判读。固定口径：缺时辰只缺时辰类 Y1，不缺其它药；缺时辰主要降低 EP 精度，不得因缺时辰一概把非时辰 Y1 降为弱候选。

## 五、A1-A5 旧错结构卡

只拦路径，不给答案。命中者必须执行必拦句、必查项、禁判句。完整旧盘、原判、反馈、实际结果归 L5 观察库，不进实时主链。

**A1｜约定执行 / 续费成交类·过程压缩误判终止**
- 触发：约定执行 / 续费 / 付款 / 到场 / 回复 / 报名确认 / 短周期履约；B1 已见（化退、伏空、世弱、应弱、迟疑、承接线受压），同时 Y1 在场（动财生世、化财生世、应爻接住 C1、行动方值日、付款 / 到场 / 确认承接可接）。
- 旧错：把“Y1 已到 B1 但只落承接 / 压缩端”误判为“Y1 全断、B1 闭合”，压缩链误判为终止链。
- 必拦：化退伏空世弱应弱只说明 B1 存在，不等于无药；Y1 已接 C1 不得直接判终局利空。
- 必查：Y1 是否到 B1；是只落承接还是已落验为付款 / 到场 / 续费 / 确认 / 完成。
- 禁判：未说明 B1 闭合且 Y1 不到病前，不得判不付 / 不来 / 不续 / 不成。

**A2｜收入 / 数量增减类·压缩链误判倒挂**
- 触发：收入 / 金额 / 数量 / 盈亏 / 增减比较；B1 已见（财化兄、兄弟克财、财受冲克、财空财弱、化泄化退），同时 Y1 在场（财源在、财线可归世、到账线可接、增量未断、日月动爻有生扶引动）。
- 旧错：把“B1 压缩 Y1 幅度”误判为“Y1 不存在 / 不到病”，增幅压缩误判为倒挂 / 不增加 / 低于基准。
- 必拦：财受压是病不等于无药；Y1 能落验但力弱应归成而不多 / 增幅压缩，不得直接判倒挂。
- 必查：题眼是“有没有增加”还是“增加多少”；Y1 是否落验为实际增加 / 到账 / 高于基准；是否有金额锚。
- 禁判：无金额锚不得外放具体百分比 / 差距 / 倍数；Y1 能落验时不得把压缩病写成终止病。

**A3｜审核 / 鉴定 / 评级类·过程偷换目标等级**
- 触发：审核 / 鉴定 / 评级 / 证书等级 / 伤残等级 / 资质级别；B1 见于目标等级线受冲克破散、化父被伤、等级结论线不归世；Y1 见于官父链 / 报告线 / 文书线 / 流程线 / 材料线。
- 旧错：把“Y1 只落流程 / 报告 / 文书端”误判为“已落验为目标等级结论成立”，过程药误判为终局药。
- 必拦：报告会出、流程会走、材料被收，只说明 Y1 进入承接端，不等于目标等级落验。
- 必查：Y1 是否真正落到“目标等级结论成立 / 报告认定该级别 / 资格级别给出”。
- 禁判：Q4b 未落到目标等级结论成立前，不得判成。

**A4｜安危死亡类·双向防错**
- 第一面（防误升安全）：线索不是活讯，活讯不是安全，死亡终态象未坐实也不是安全；用神显形不得直接升用神可确认；用神可确认不得直接升用神得救；死亡终态象未坐实不得反推安全。
- 第二面（防病重误判无药）：当 B1 重、U1 受伤、J1 旺，但 Y1 尚在、Y1 可能到 B1、死亡终态象未坐实时，不得仅凭鬼旺 / 化鬼 / 父母空 / 救应弱直接判死亡终态象强、救不过来或普通高危默认。必须回到 F5 病药四问。
- A4 不给答案，只强制回到 F5 病药四问与 F6 安危双层外放。

**A5｜安危抢救类·病重吞药**
- 触发：急性抢救 / 中毒 / 事故急救 / 病危 / 昏迷 / 医院处置 / 现场救援；B1 明显主裁倾凶，但存在 Y1 原始候选（父母医护、子孙救应、日月生扶、动变通关、合化救应、填实引拔），且 U1 未坐实绝断。
- 旧错：把鬼旺 / 化鬼 / 财生鬼 / 父母空 / 救应弱直接压成救不过来 / 死亡终态象强 / 普通高危默认，吞掉 Y1。
- 必拦：病重不等于无药；鬼旺不等于救不过来；父母空不等于医护无效；救应弱不等于救应全断；**动化鬼不等于无条件死亡终态象强，须看是否有解除、引拔、回生闭环**。
- 必查：B1 / Y1 是什么；Y1 能否到 B1；Y1 到 B1 后是只落承接还是落验为脱险 / 稳定 / 确认；U1 本体硬证是否被解除或引拔。
- 禁判：未说明 Y1 为何不能到 B1 或为何不能落验前，不得输出救不过来默认；不得把“医护接入”写成“医护救回”；**不得把“动化鬼”直接写成“不可回转终止态”，除非同时证明无解除、无引拔、无回生闭环**。

## 六、缺时辰病药纪律

缺起卦时辰时不得脑补，不得用系统时间 / 投喂时间 / 消息发送时间替代。缺时辰只影响时辰类 Y1，不影响：月建、日辰、动变、飞伏、世应、父母医护线、子孙救应线、同功能补位、非时辰填实、非时辰引拔、近日值日填实。

不得登记为有效 Y1 到病：时辰生扶、时辰临爻、时辰触发、时辰—近日值日兑现链。仍可正常判读的非时辰药证：日辰生扶、月建生扶、父母医护承接、子孙救应、动变通关、伏神引拔、近日值日填实、同功能补位。

固定口径：缺时辰只缺时辰类 Y1，不缺其它药；缺时辰主要降低 EP 应期精度；不得因缺时辰一概把非时辰 Y1 降为弱候选。

## 十四、安危措辞替换清单

外放层全文替换：已亡坐实 → 死亡终态象强（现实须确认）；已亡未坐实 → 死亡终态象未坐实；死亡终态层 → 死亡终态象层；判已亡 → 判死亡终态象强；不得判已亡 → 不得外放现实死亡确认。

关键句：死亡终态象强 ≠ 现实死亡已确认；死亡终态象未坐实不得反推安全；高危不安全 ≠ 死亡终态象强；安全未确认不得说成危险也不得说成平安；卦象解读不得替代医院 / 警方 / 家属 / 现场救援或专业机构确认。
