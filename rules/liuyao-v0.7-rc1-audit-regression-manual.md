## 二、药证复核清单（Y1 药证工具，归 F5 后台）

原“救应承接强证复核闸”降格为药证复核清单，不再与病药四问并列成主裁轴。用于判断 Y1 是否存在、是否到 B1、是否落验。

药证状态三档：

```
有效药证：Y1 能到 B1，且能落现实承接或落验，不被强反证压倒。
弱药候选：Y1 有象，但只能弱接触、只落承接、力量不足或路径不闭合。
未命中：无 Y1，或 Y1 被空破伏合绊克泄阻断，或与 B1 无作用。
```

有效药证项数处理：

```
0 项：Y1 不成立，不干扰主裁。
1 项：记录 Y1 候选，不得写“全无药”。
2 项：强复核；若仍判高危或不成，须说明 Y1 为何不能落验。
≥3 项：回退 F5 重答病药四问。
```

特殊闭环药证（现实医护承接闭环、时辰兑现链）按有效药证处理；仅命中特殊组合单项，不触发闭环。缺时辰者，时辰类 Y1 不计有效药证，非时辰 Y1 正常判读。

## 三、A1–A5 旧错结构卡

旧错结构卡只拦路径，不给答案。命中者必须执行必拦句、必查项、禁判句。完整旧盘、原判、反馈、实际结果归 L5，不进正文。

### A1｜约定执行 / 续费成交类·过程压缩误判终止类

- **触发结构**：约定执行、续费成交、付款、到场、回复、报名确认、短周期履约类；B1 已见（化退、伏空、世弱、应弱、承接线受压），同时 Y1 在场（动财生世、化财生世、应爻接住 C1、行动方值日、付款 / 到场 / 确认承接线可接）。
- **旧错路径**：把“Y1 已到 B1 但只落承接端或压缩端”，误判为“Y1 全断、B1 闭合”，把压缩链误判为终止链。
- **必拦句**：化退、伏空、世弱、应弱只说明 B1 存在，不等于无药；Y1 若已接 C1，不得直接判终局利空。
- **必查项**：Y1 是否到 B1；Y1 是只落承接端，还是已落验为付款、到场、续费、确认、完成动作。
- **禁判句**：未说明 B1 闭合且 Y1 不到病前，不得判不付、不来、不续、不成。

### A2｜收入 / 数量增减类·压缩链误判倒挂类

- **触发结构**：收入、金额、数量、盈亏、增减比较类；B1 已见（财化兄、兄弟克财、财受冲克、财空财弱、化泄、化退），同时 Y1 在场（财源仍在、财线可归世、到账线可接、增量线未断、日月动爻仍有生扶或引动）。
- **旧错路径**：把“B1 压缩 Y1 的幅度”误判为“Y1 不存在或不到病”，把增幅压缩误判为倒挂、不增加、低于基准。
- **必拦句**：财受压是病，不等于无药；Y1 能落验但力量弱，应归为成而不多、增幅压缩，不得直接判倒挂。
- **必查项**：题眼是“有没有增加”还是“增加多少”；Y1 是否能落验为实际增加 / 到账 / 高于基准；是否有金额锚。
- **禁判句**：无金额锚不得外放具体百分比、差距、倍数；Y1 能落验时不得把压缩病写成终止病。

### A3｜审核 / 鉴定 / 评级类·过程偷换目标等级类

- **触发结构**：审核、鉴定、评级、证书等级、伤残等级、资质级别类；B1 见于目标等级线受冲克破散、化父被伤、等级结论线不归世；Y1 见于官父链、报告线、文书线、流程线、材料线。
- **旧错路径**：把“Y1 只落流程端、报告端、文书端”误判为“Y1 已落验为目标等级结论成立”，把过程药误判为终局药。
- **必拦句**：报告会出、流程会走、材料被收，只说明 Y1 进入承接端，不等于目标等级落验。
- **必查项**：Y1 是否真正落到“目标等级结论成立 / 报告认定该级别 / 资格级别给出”。
- **禁判句**：成法未落到目标等级结论成立前，不得判成。

### A4｜安危死亡类·双向防错类

- **第一面（防误升安全）**：线索不是活讯，活讯不是安全，死亡终态象未坐实也不是安全。用神显形不得直接升用神可确认；用神可确认不得直接升用神得救；死亡终态象未坐实不得反推安全。
- **第二面（防病重误判无药）**：当 B1 重、U1 受伤、J1 旺，但 Y1 尚在、Y1 可能到 B1、死亡终态象未坐实时，不得仅凭鬼旺、化鬼、父母空、救应弱直接判死亡终态象强、救不过来或普通高危默认。必须回到 F5 病药四问。
- **A4 不给答案，只强制回到病药四问与安危双层外放。**

### A5｜安危抢救类·病重吞药类

- **触发结构**：急性抢救、中毒、事故急救、病危、昏迷、医院处置、现场救援等；B1 明显，主裁倾凶；但存在 Y1 原始候选（父母医护、子孙救应、日月生扶、动变通关、合化救应、填实引拔），且 U1 未坐实绝断。
- **旧错路径**：把鬼旺、化鬼、财生鬼、父母空、救应弱直接压成救不过来、死亡终态象强或普通高危默认，吞掉 Y1。
- **必拦句**：病重不等于无药；鬼旺不等于救不过来；父母空不等于医护无效；救应弱不等于救应全断。
- **必查项**：B1 是什么；Y1 是什么；Y1 能否到 B1；Y1 到 B1 后是只落承接端，还是能落验为脱险、稳定、确认。
- **禁判句**：未说明 Y1 为何不能到 B1、或 Y1 到 B1 后为何不能落验前，不得输出救不过来默认。

## 六、证据编号去重与 EV 回引规则

同一事实证据只书写一次，编号 EV1、EV2、EV3。A4、A5、药证复核清单、D2a、D2c 可共同引用同一 EV 编号，但法源状态、触发状态、执行状态须分别登记。**事实可合并，闸位不可合并。**

EV 回引硬规则：

```
凡登记“已执行”，必须绑定 EV 编号。
EV 编号必须指向本次输出中已经实际出现过的判断句、关系句或病药句。
审计行必须回引该 EV 的关键词。
若找不到可回引文字，不得登记已执行，只能写未执行、未触发或回退。
```

格式示例：

```
EV1：F2 已写“R1 为五爻父母酉金，承载目标等级结论”。
EV2：F5 已写“B1 为 R1 被月破且不归世，属落点病”。
EV3：F5 已写“Y1 为二爻子孙寅木发动克鬼，但被日冲，故只弱接触”。

审计：
G1 三线定位：已执行，依据 EV1“R1 为五爻父母酉金”。
G2 合冲生克复核：已执行，依据 EV3“子孙寅木发动克鬼但被日冲”。
G3 伏空刹车：未触发。
```

禁止空审计（无 EV 回引即视为未执行）：

```
G1：已执行。
G2：已执行。
D2a：已执行。
```

- **本盘表现**：二爻官鬼辰土动，合上爻父母酉金，应为病鬼入医护处置端；漏列此象易导致凶象误压。

## 十、双向防错对照母盘

- **母盘名称**：E-W001 / E-W002 双向防错对照母盘。
- **题型**：安危抢救 / 中毒急救 / 急性病危。
- **核心结构**：兄弟亥水动化官鬼戌土，官鬼辰土动，父母酉金应临月，子孙寅木弱，申日 / 申支反馈救活。
- **实际结果**：申日 / 申支出空转实，金气起生亥水，现实反馈救活。
- **正确回填**：
```
病药归层：终局利成。
过程语：鬼门关重危抢回。
安全层：抢救过来 / 平安倾向，但须保留“重危抢回”过程限定。
死亡终态象层：未触发。
后续恢复：另占。
```
- **正确卦理三项叠加**：①医护承接成立（辰鬼合酉父，病鬼入医护处置端）；②父母医护线有力（父母酉金临月，本气当令）；③药能回生主用（申日 / 申支金气转实生亥水，形成病鬼入医方→医护线转实→金气生亥水→主用被救回之闭环）。
- **验收标准**：
```

不得把辰酉合直接写成鬼克解除。
不得把医护接入直接写成抢救成功。
```

- **双向防错说明**：本盘验证两个镜像旧错——①漏看 J1 / B1 与父母医护线关系导致凶象误压；②夸大医护接入导致真死判活。本盘不证明“凡动鬼合父母皆能救活”，只证明：当医护承接成立、医护线有力、且药能回生 U1 本身形成现实闭环时，可归终局利成。若下一盘仅有医护接入而 U1 本体硬证未解除，仍应归高危救应未断附记或终局利空候选。
