### 六、基础术语

- 题眼：卦主真正问的结果对象。
- 结果线 R1：直接承载终局结果的用神、应爻、卦身或结果端。
- 落地线 LD1：能把结果推进到现实动作的爻线。
- 承接线 C1：结果与世爻或卦主现实端之间的连接链。
- 过程证：只说明事情有动、有人理、流程推进、消息出现、状态变化，不直接证明终局结果成立。
- 终局证：能直接证明终局结果在现实层面成立的证据。
- 现实落验：钱到账、名归身、级成立、证出、物到、人确认、关系恢复、约定完成、医方确认脱险等。
- 病：阻断目标结果、伤害 U1、压制 R1、断开 LD1 / C1、导致现实终止机制成立的主因。
- 药：解除病象、救应 U1、通关 J1、填实空伏、引动落地、承接现实动作的力量。
- 药到病：Y1 实际作用到 B1。
- 药落验：Y1 到 B1 后落到本题终局现实结果。
- 弱接触：Y1 有象，但力量不足、路径不闭合，或只落承接端。
- 只落承接：Y1 能接入现实承接端（医护接入、流程启动、通知出现、订单生成），但未完成终局结果。
- VV 判定：Visual Verification，锁盘可读性校验。盘面可读、世应可辨、动爻可辨、旬空可判四项全满足才 PASS。
- 人象合一判定：占事对象为人时，盘中 U1、对象爻、世应或相关人象是否稳定对应现实中的该人。若只见线索象、消息象、物象、机构象，不得直接当作本人状态；不足时写“未稳”或“不足”，不得把线索显形直接升为安全确认。

安危类术语：

- 用神显形：有线索、有下落、有消息端、有动静。不等于活讯或安全。
- 用神可确认：有本人回应、家属确认、医院确认、警方确认、现场确认、视频电话核验等现实确认链。
- 用神得救：U1 之外有 Y1，且 Y1 能到 B1，并能落到现实救应动作。
- 用神绝断：U1 重伤，空破墓绝伏不出，J1 / B1 压顶，Y1 全断，现实终止机制闭合。
- 高危救应未断附记：安危类 B1 已重，但 Y1 未断，Y1 能到 B1 或只落承接端，死亡终态象未坐实时的附记。它不是第三终态。

```

冲合十诀：冲合先看角色，再看方向，后看落点。冲合所作用之爻若不是 U1、R1、LD1、C1、J1、B1、Y1、Y2，默认不入终局强证，只作过程或成色候选。

合五判：合来（向世 / 卦主现实端靠近）；合去（离世 / 离身 / 归外）；合住（被锁、暂缓，不等于不成）；合绊（贪合忘生忘克，忌神被合绊偏利、救应被合绊偏不利）；合化（看化出五行利 U1、利 J1，还是只成过程象）。

冲五判：冲实（空伏弱待动者被冲起得触发）；冲散（已成之合 / 承接 / 聚力被冲开）；冲破（根基受损，尤其月破日破及 R1 / LD1 / C1 被破）；冲动（静象被激发，只算触发）；冲走（U1 / R1 / LD1 / C1 / 财 / 名 / 救应线离世离身）。

十二长生纪律：只作气数 / 状态 / 应期辅助，不作独立生死裁决层。高风险题型中可辅助判断 U1 余气、Y1 救应余气、J1 病象强弱和应期转机，但不得单独判平安、死亡终态象强、获救或救不过来。生死安危仍以 U1、J1、子孙救应、父母医护、动变生克、空破墓绝、飞伏出入、现实承接链综合裁定。

双面取象（择面三句）：本盘取何面；取此面的卦理理由；另一面为何不取或为何仅入过程层。以下必须完整甲乙双写：进入 F5 前凡关键象同时可能构成 B1 或 Y1 者；安危类进入 F6 双层外放前凡线索 / 活讯 / 安全 / 死亡终态象边界不清者；A1-A5 命中者；F6 同数决胜或 Q0 反向候选足以改判者；审计要求回退者。静卦或无动爻盘中，涉及动变、化爻、回头克、化退化进、动鬼合父母等登记为未触发 / 不适用，不得脑补动爻。

### 十四、F5 病药归层

F5 是主轴核心。进入 F5 后，先执行用神气象七字诀，再执行病药四问，再执行归层。未完成 F5，不得进入 F6。

**F5.1 用神气象七字诀**：得令、得位、得助、不空、不伏、不绝、不墓。

- 得令：得月建生扶 / 比和 / 临月，或至少不受月建重克、月破。
- 得位：居世 / 应 / 结果位 / 承接位 / 用神本位，或伏神得飞神护提而可用。
- 得助：得日辰 / 动爻 / 原神 / 同功能补位 / 生扶通关之一。
- 不空：不落日空；若空，须有出空、填实、冲实、值日等条件方可作待实。
- 不伏：不伏；若伏，须有飞神生扶、冲提、引拔、出伏条件方可作待出。
- 不绝：非化绝 / 非绝地重锁；若见绝，须有生扶、通关、引拔方可缓解。
- 不墓：非入墓 / 化墓 / 墓闭；若入墓，须有冲墓、开墓、引出条件方可缓解。

四项以上为用神有气；二至三项为弱气；零至一项为绝气。用神气象只作病药归层前置判据，不得单独越过病药四问直接裁决成败或生死。

**F5.2 病药四问**：

第一问 · 本盘之病 B1 是什么？（编号 B1 / B2）判病三类——外病（忌神 / 官鬼 / 兄弟 / 仇神 / 外部阻力发动得势，直克 U1 / R1 / LD1 / C1）；内病（U1 自身空破墓绝伏不出、化退化泄化鬼化绝回头克）；落点病（R1 / LD1 / C1 被冲散克断、空伏不出、合去合绊化泄，结果落不到现实动作）。主病优先级：直接造成现实终止者优先，直接伤 U1 者次之，只造成过程阻滞者再次之。

第二问 · 本盘之药 Y1 是什么？（编号 Y1 / Y2）药可为原神、子孙、父母医护、日月生扶、动爻通关、冲实填实、合化救应、同功能补位、机构 / 文书 / 医护承接等。

第三问 · Y1 能否到 B1？药必须实际作用到 B1；只生无关爻、只临日月、只成背景喜象、只在旁边而不作用病点者不算到病；被空破伏合绊受克化泄化退而不能接触 B1 者记为未到病。药到病三路径——直接生克 / 合化通关 / 动变引拔。空药伏药墓药须有出空出伏开墓值日冲实引拔条件方可算到病；合化药须看合化后五行是否利 U1，利忌神或只成过程象不算有效到病。**只许三档：到病 / 弱接触 / 未到病。**

第四问 · Y1 到 B1 后能否落验？须落到本题现实目标：钱到账、名归身、级成立、物到手、人确认、关系实际恢复；抢救须见医方确认、生命体征稳定、脱险或本人可确认。仅流程启动、医护接入、消息出现、承接候选，最多算承接端，不等于终局落验。**只许三档：已落验 / 只落承接 / 未落验。**

**F5.3 病药归层**（只许：终局利成 / 终局利空 / 过程助成 / 过程阻滞 / 条件性待实 / 高危救应未断附记）：

- 无明显 B1，U1 有气，R1 / LD1 / C1 闭合 → 终局利成。
- 有 B1，有 Y1，Y1 到 B1，且能落终局现实结果 → 终局利成。
- 有 B1，有 Y1，Y1 到 B1，但只落承接端：安危类 → 高危救应未断附记 / 重危有药候选；非安危类 → 过程助成 / 条件性待实。
- 有 B1，有 Y1，但 Y1 到不了 B1 → 过程阻滞 / 救应弱候选。
- 有 B1，有 Y1，但 Y1 被空破伏合绊受克化泄化退，待填实或待引动 → 条件性待实 / 低信候选。
- B1 闭合，无 Y1，或 Y1 全断，现实终止机制成立 → 终局利空。
- 安危类中 B1 闭合、救应全断、终止信号成立、U1 入不可回转终止态 → 死亡终态象强候选，仍须过 F6 安危双层外放门。

高危救应未断附记只适用于安危、失踪、抢救、中毒、事故急救、急性病危、寿元、重大疾病等高风险题型；非安危类不得使用该名称。

固定拦句：药到病不等于药落验；医护接入不是医护救回；识别父母医护线不等于自动终局利成；必须正向证明 U1 本体硬证被解除或被引拔，方可上收终局利成；不得因“安危类谨慎”压低已闭合的终局利成链；不得因“医护接入”抬高未闭合的高危盘；不得以“答不出反向理由”作为终局利成依据。

高风险题型、A4 / A5 触发盘、B1 / Y1 边界盘，F5 后加握手点：

```
请确认 F5 病药四问与归层无误，再进入 F6 裁决。
```

### 十五、F6 裁决

F6 只转换 F5 归层和前文强证，不得新增证据。非安危类进入 F6b，安危类进入 F6a。

### 十六、F6a 安危类双层外放门

安危类默认站位为高风险待裁。未过安全门，不得默认平安。安全层与死亡终态象层必须分开裁定。

安全层三档：平安倾向 / 安全未确认 / 高危不安全。
死亡终态象层三档：死亡终态象强 / 死亡终态象未坐实 / 未触发。
用神状态档四档：用神显形 / 用神可确认 / 用神得救 / 用神绝断。用神状态档只作 F6a 内部判据和卦象状态描述，不单独替代安全层，不单独替代死亡终态象层，也不得替代现实确认。

死亡终态象强 ≠ 现实死亡已确认；死亡终态象未坐实不得反推安全；高危不安全 ≠ 死亡终态象强；安全未确认不得说成危险，也不得说成平安。

**F6a-1 甲乙路径建模**：甲路径（暂隐、人还在、可确认、可得救）；乙路径（不现、绝断、死亡终态象强候选）。硬信号：U1 飞伏溃散无引拔；J1 / B1 官鬼白虎玄武直临或动克 U1；U1 与死因象高度同构且现实终止机制闭合；U1 空破墓绝伏不出且无出空出伏冲实引拔；Y1 全断或到不了 B1。软信号：归魂、游魂、遁象、现实高风险场景、消息断裂、承接链迟滞。硬信号为零不得乙优先；硬信号一条且软信号≥一条，乙仅作候选；硬信号两条以上乙可优先建模，但未过死亡终态象门槛不得外放现实死亡确认。

**F6a-2 死亡终态象门槛**（三项全过才可升死亡终态象强）：

```
第一，救应全断（Y1 全断或到不了 B1）。
第二，终止信号成立（现实终止机制在卦象中闭合）。
第三，U1 入不可回转终止态，如空绝墓三重锁且无引拔、动化绝且无引拔、动化鬼且未被解除、伏不出且无引拔。
```

三项缺一，不得外放死亡终态象强。动化鬼、化绝、入墓、伏不出等，只在无解除、无引拔、无回生闭环时才可作为不可回转终止态证据。死亡终态象未坐实不得反推安全。

**F6a-3 甲乙路径并列校验**：乙路径优先后，若甲路径强证≥二条且有消息链 / 机构链 / 医护链 / 家属确认链，必须回退甲路径或并列建模。并列建模只为双层外放服务，不得写成成败两可。

**F6a-4 安全门槛**（至少两项且无强反证压顶方可判平安倾向）：U1 在场且不空不伏不绝；Y1 明确在场能到 B1 并能落现实；J1 / B1 不旺或被制 / 合绊 / 泄 / 通关；有明确用神可确认链。安全门槛不通过只说明不得判平安，不自动等同高危。

**F6a 固定输出**：

```

死亡终态象层结论：死亡终态象强 / 死亡终态象未坐实 / 未触发。
附记：高危救应未断 / 重危有药候选 / 鬼门关格候选 / 未触发。
概率档：高 / 中高 / 中 / 不足。
过程语：顺安 / 待核实 / 高危待核实 / 重危有药候选。

### 十七、F6b 非安危类裁决
