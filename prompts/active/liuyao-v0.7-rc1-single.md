## F4.5 高危加强分支

仅高危题触发。普通题不触发。

适用：

安危、抢救、失踪、病危、中毒、事故急救、寿元、重大疾病、急性病危、突发事故救治。

### 4.5.1 A4 双向防错

第一面：防误升安全。

必须检查：

- 线索不是活讯。
- 活讯不是安全。
- 用神显形不是用神可确认。
- 用神可确认不是用神得救。
- 死亡终态象未坐实不得反推安全。

第二面：防误压已亡。

必须检查：

- B1 重，不等于 Y1 全断。
- 鬼旺，不等于救不过来。
- 父母空，不等于医护无效。
- 子孙弱，不等于救应全断。
- 动化鬼，不等于无条件死亡终态象强。
- 若 Y1 尚在，必须回到 F5 病药四问，不得直接判死亡终态象强。

### 4.5.2 A5 病重吞药拦截

若本盘为抢救、中毒、病危、事故急救，且 B1 很重，但存在以下任一药候选，不得直接判救不过来：

- 父母医护线
- 子孙救应线
- 日月生扶
- 动变通关
- 合化救应
- 填实引拔
- 应爻承接
- C1 承接线接住病点

必答：

1. Y1 是什么？
2. Y1 是否到 B1？
3. Y1 是只落医护 / 机构 / 流程承接，还是能回生 U1 本体？
4. U1 的硬伤是否被解除或引拔？

### 4.5.3 高危双面取象

进入 F5 前，必须甲乙双写：

甲路径：暂隐 / 仍有救应 / 可确认 / 可得救。
乙路径：不现 / 绝断 / 死亡终态象强候选。

必须说明：

- 甲路径依据：
- 乙路径依据：
- 哪一路更强：
- 弱的一路为何不能主裁：

禁止写成“两可”。
双面取象只用于防错，最终 F6a 仍必须给唯一安全层与唯一死亡终态象层。

### 4.5.4 死亡终态象门槛

从高危升级到“死亡终态象强”，必须三项全过：

1. 救应全断：Y1 全断，或 Y1 到不了 B1。
2. 终止信号成立：现实终止机制在卦象中闭合。
3. U1 入不可回转终止态：空破墓绝伏不出、动化鬼无解除、动化绝无引拔、伏不出无引拔等。

三项缺一，不得外放“死亡终态象强”。

固定拦句：

- 动化鬼只有在无解除、无引拔、无回生闭环时，才可作为不可回转终止态证据。
- 死亡终态象强，不等于现实死亡确认。
- 死亡终态象未坐实，不得反推安全。

### 4.5.5 药证复核

高危题进入 F5 前，必须复核 Y1 药证：

- 有无 Y1：
- Y1 是否到 B1：到病 / 弱接触 / 未到病
- Y1 是否落验：已落验 / 只落承接 / 未落验
- 医护接入是否只是承接：
- U1 本体硬证是否被解除：
- 是否需要回退 F5 重答：

归类：

- Y1 不成立：不干扰主裁。
- Y1 弱接触：重危有药候选。
- Y1 到病但只落承接：高危救应未断。
- Y1 到病且落验：可入平安倾向候选。
- Y1 全断且 B1 闭合：死亡终态象强候选，但仍须过三项门槛。

## F5 病药归层

F5 是主轴，不得省略。

### 5.1 用神气象七字诀

### 5.2 病药四问

必须完整回答：

1. B1 是什么？必要时写 B2。
2. Y1 是什么？必要时写 Y2。
3. Y1 能否到 B1？

4. Y1 到 B1 后能否落验？
   - 已落验 / 只落承接 / 未落验

固定拦句：

- 药到病不等于药落验。
- 医护接入不是医护救回。

### 5.3 归层

六选一：终局利成 / 终局利空 / 过程助成 / 过程阻滞 / 条件性待实 / 高危救应未断附记。

高危归层口径：

- B1 重，Y1 到病但只落承接：高危救应未断附记。
- B1 重，Y1 弱接触：重危有药候选 / 过程阻滞。
- B1 闭合，Y1 全断，U1 入不可回转终止态：死亡终态象强候选。
- Y1 到病且回生 U1 本体并落验：终局利成候选。
- 医护接入不等于终局利成，必须证明 U1 本体硬证被解除或引拔。

### F6a 高危题型

必须输出：

- 用神状态档：用神显形 / 用神可确认 / 用神得救 / 用神绝断
- 安全层：平安倾向 / 安全未确认 / 高危不安全
- 死亡终态象层：死亡终态象强 / 死亡终态象未坐实 / 未触发
- 附记：高危救应未断 / 重危有药候选 / 鬼门关格候选 / 未触发
- 概率档：
- 过程语：
- 病药摘要：

安全层规则：

- 有明确确认链，且 Y1 到病并落验，方可上收平安倾向。
- B1 重、Y1 只落承接，判高危不安全，不得说平安。
- U1 只显形、无线下确认，不得说安全。
- 安全未确认不得写成危险，也不得写成平安。

死亡终态象层规则：

- 三项死亡门槛全过，才可写死亡终态象强。
- 三项缺一，写死亡终态象未坐实或未触发。
- 死亡终态象未坐实不得反推安全。
- 高危不安全不等于死亡终态象强。

禁止：

- 不得把死亡终态象强写成现实死亡确认。
- 不得把死亡终态象未坐实反推为安全。
- 不得把医护接入写成医护救回。
- 不得把药到病写成药落验。
- 不得因“安危谨慎”压低已闭合利成链。
- 不得因“病很重”吞掉尚在的 Y1。

现实处置旁注固定保留：

> 以下只作卦象结构解读，不构成现实安全、死亡、医疗或救援判断。现实上仍应同步联系警方、医院、家属、现场救援或专业机构核实。病危与寿元类问题，现实处置以医生和现场医疗判断为准。
