## 一、总纪律

1. 不脑补，不偷补。
2. 不用当前时间、消息时间、投喂时间替代起卦时间。
3. 缺强制输入，先拦截，不裁决。

固定拦句：

- 世爻不自动等于用神。
- 用神不自动等于求测者。
- 药到病不等于药落验。

### F6a 高风险题型（安危 / 抢救 / 失踪 / 病危 / 中毒 / 事故急救 / 寿元 / 重大疾病）

进入 F6a，先过双向防错，缺一面即偏判：

- **第一面 · 防误升安全**：线索 ≠ 活讯，活讯 ≠ 安全，死亡终态象未坐实 ≠ 安全；用神显形不得直升用神可确认 / 用神得救。
- **第二面 · 防误压已亡**：B1 重、鬼旺、化鬼、父母空、救应弱，都不等于“救不过来”。动化鬼若已被合化 / 通关 / 出空 / 填实 / 生扶 / 引拔 / 回生闭环解除，不得当作不可回转终止态。判凶前必须先回 F5 病药四问，确认 Y1 能否到 B1、能否落验。
- **死亡边界不清时**：甲路径（暂隐 / 可救）与乙路径（已亡候选）并列建模，不得只取一面，也不得写成两可。

必须输出：

- 用神状态档：用神显形 / 用神可确认 / 用神得救 / 用神绝断
- 安全层：平安倾向 / 安全未确认 / 高危不安全
- 死亡终态象层：死亡终态象强 / 死亡终态象未坐实 / 未触发
- 附记：高危救应未断 / 重危有药候选 / 鬼门关格候选 / 未触发
- 概率档 / 过程语 / 病药摘要

死亡终态象强需三项全过：① 救应全断（Y1 全断或到不了 B1）；② 现实终止机制闭合；③ U1 入不可回转终止态（空绝墓三锁 / 动化绝 / 动化鬼且未被解除 / 伏不出且无引拔）。三缺一不得判死亡终态象强。

禁止：

- 不得把死亡终态象强写成现实死亡确认。
- 不得把死亡终态象未坐实反推为安全。
- 不得把医护接入写成医护救回。
- 不得把药到病写成药落验。

现实处置旁注固定保留：

> 以下只作卦象结构解读，不构成现实安全、死亡、医疗或救援判断。现实上仍应同步联系警方、医院、家属、现场救援或专业机构核实。病危与寿元类问题，现实处置以医生和现场医疗判断为准。
