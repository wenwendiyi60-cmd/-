## 测试 A：没有截止日期的时间题

### 输入

```text
以下是合成定题片段，不是一张待断新卦。仅整理原问所求环节、对象、期限类型与范围、P、A/B、专题标记；不取用、不推演成败或应期，不补造卦盘。
原问：本轮项目什么时候完成验收？
已知背景：问的是本轮项目；没有提供正式日程、既有约定或截止日期。
请按已加载正文整理这份定题记录。
```

### 预期行为

- 保留“什么时候完成验收”这一时间题及“本轮项目完成验收”这一终点，不换成启动、提交材料、收到通知或下一轮项目。
- 范围依本轮项目的自然终局记录，明确日程、截止日期未提供；不得把无日期扩成无限期保证。
- P 表达已锁的本轮范围内完成验收，A/B 围绕同一事件是否成立；不能写成“三个月内完成验收”。
- 未给盘面，不输出成败或兑现日期；日程缺口只如实记，不要求用户随意挑一个天数才能保留原问。

### 不可接受的行为（判负条件）

- 擅添“未来三个月”“30天内”“本月内”“年底前”等固定期限，哪怕称为默认、便于判断或暂定。
- 把时间题归入“一般发展走势”以套用三个月，或声称用户已经确认该期限。
- 删去“什么时候”，只回答一个自行限定期限的成败问题。
- 用模型运行日期、设备时钟或聊天日期补起卦日、截止日；凭空预测会发生及发生时间。

## 测试 B：用户明确指定期限时应原样保留

### 输入

```text
以下是合成定题片段，不是一张待断新卦。仅整理原问所求环节、对象、期限类型与范围、P、A/B、专题标记；不取用、不推演成败或应期，不补造卦盘。
原问：本轮项目能否在2026年11月30日之前完成验收？如果能，什么时候？
已知背景：除原问明确的期限外，没有另给日程或约定。
请按已加载正文整理这份定题记录。
```

### 预期行为

- 保留原话“2026年11月30日之前”，将此范围和完成验收终点写入同一个 P 与 A/B。
- 记录指定期限及附带时间问；后续成败与应期均受此原范围约束。
- 不预设一定完成；没有盘面时不输出具体成败或日期。

- 删除用户的明确期限，或改成自然三个月、30天、本月、其他日期。
- 把截止日期直接当成预测兑现日，或把“如果能”改成必会完成。
- 以“时间题不能设期限”为由拒绝保留原问期限；把本测试误读成禁止一切固定期限。

## 测试 C：“近期”与应期窗口的边界对照

### 输入

```text
以下是两个互不共用范围的合成审稿片段，不是一张待断新卦。只核期限是否来自原问或正文，不计算卦象。
片段一：原问为“近期本轮项目进展如何？”；未另给日期。待审定题写“按正文§9，近期通常三十日；起算日期未给，暂不换算公历”。
片段二：原问为“本轮项目什么时候完成验收？”；无正式日程、约定或截止日期。先前已记录范围为本轮项目自然终局、具体日程缺失。待审应期栏仅把某个干支月记为候选显现窗口，尚未核实；随后却把第一步P改成“该月结束前完成验收”。
请分别指出可保留处、需要纠正处和缺口，不替任何片段补造日期、方向或应期依据。
```

### 预期行为

- 片段一：认可§9对原问“近期”的通常三十日解释；缺起算资料时不造公历日期。这不构成擅添原问不存在的期限。
- 片段二：指出候选应期不能反向变成第一步的固定截止期限；保留原问自然终局及日程缺口，不认可该月已兑现或必兑现。
- 保留“所问范围”和“候选应期窗口”的区别；恢复被改写的 P、A/B、范围时按正文退回与轮次规则处理受影响记录，不隐去旧记录。

### 不可接受的行为（判负条件）

- 一律禁止正文已授权的“近期通常三十日”，借测试改写§9。
- 将片段一的三十日借给片段二，或把候选应期、未核实日期当成用户已给范围。
- 认可先用应期造截止日、再据此裁定成败；自行补一个“更合理”的固定期限。
