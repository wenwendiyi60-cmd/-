# 六爻大世界 v0.7-RC1-final｜高风险专用模板（安危/抢救/失踪/病危）

> 适用题型：安危、失踪、抢救、中毒、事故急救、急性病危、寿元、重大疾病。
> 目标：一键保留安全红线，不把流程象误当终局象。
> 配套：完整口令见 `prompts/active/liuyao-v0.7-rc1-execution-prompt.md`。

---

## 高风险固定纪律

- 不得把卦象结论当现实确认。
- 不得把“死亡终态象强”写成现实死亡确认。
- 不得把“死亡终态象未坐实”反推为安全。
- 医护接入不是医护救回。
- 药到病不是药落验。

---

## 快速执行骨架（F1→F7）

### F1 锁盘（摘要）
- 版本回执
- 占事原文
- 题型初判：高风险题型 + 已激活红线
- VV 判定
- Visual Anchor + 七列表

### F2 定体（必填）
- 题眼：
- U1：
- R1：
- LD1：
- C1：
- J1：
- 人象合一判定：已稳 / 未稳 / 不足

> 安危类若线索/活讯/安全/死亡终态象边界不清，触发 F2.5 结果本体锁定（三问）。

### F3 看气（核心）
- U1/R1/LD1/C1/J1 气势
- 空破墓绝伏
- 卦情总线

### F4 断机（高风险强制项）
- J1/B1 ↔ 父母医护线（必写）
- J1/B1 ↔ 子孙救应线（必写）
- J1/B1 ↔ 应爻承接线（必写）
- U1 ↔ J1/B1
- U1 ↔ Y1
- 轻量归身三问

### F5 病药四问（整段必写）
1) B1（主病）/B2（副病）
2) Y1（主药）/Y2（副药）
3) Y1 到 B1：到病 / 弱接触 / 未到病
4) Y1 落验：已落验 / 只落承接 / 未落验

归层六选一：
- 终局利成 / 终局利空 / 过程助成 / 过程阻滞 / 条件性待实 / 高危救应未断附记

### F6a 双层外放（不可删）
- 用神状态档：用神显形 / 用神可确认 / 用神得救 / 用神绝断
- 安全层：平安倾向 / 安全未确认 / 高危不安全
- 死亡终态象层：死亡终态象强 / 死亡终态象未坐实 / 未触发
- 附记：高危救应未断 / 重危有药候选 / 鬼门关格候选 / 未触发
- 概率档 + 过程语 + 病药摘要

### F7 外放（不可删项）
- 应期精度：默认 EP0/EP1（除非闭环强证）
- 白话候选稿（一句话）
- 现实处置旁注（固定句）
- 寿元/病危类医疗优先旁注（如适用）
- 自检简码

## 现实处置旁注（固定句）

以下只作卦象结构解读，不构成现实安全、死亡、医疗或救援判断。现实上仍应同步联系警方、医院、家属、现场救援或专业机构核实。

病危与寿元类问题，现实处置以医生和现场医疗判断为准。
