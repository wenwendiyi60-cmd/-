# 六爻大世界 v0.7-RC1-final｜极简前台执行模板（F0-F7）

> 目标：仅压缩执行负担，不压缩安全负担。
> 适用：默认实时断卦（非展开审计模式）。
> 配套：完整口令见 `prompts/active/liuyao-v0.7-rc1-execution-prompt.md`；高风险题用 `liuyao-high-risk-template.md`。

---

## 使用原则（不可删）

- 仅执行前台 F0-F7。
- 不脑补，不偷补，不用当前时间替代起卦时辰。
- **F5 病药四问必须完整执行**。
- 安危类必须执行 **F6a 双层外放**。
- 必须保留现实处置旁注。
- 过程证与终局证必须分离。
- 若缺强制输入，先回问，不进入裁决。

## F5 病药归层（不可压缩）

### 5.1 用神气象七字诀
- 得令 / 得位 / 得助 / 不空 / 不伏 / 不绝 / 不墓（逐项判）

### 5.2 病药四问（必须原样完整）
1) B1 是什么？（必要时 B2）
2) Y1 是什么？（必要时 Y2）
3) Y1 能否到 B1？（到病 / 弱接触 / 未到病）
4) Y1 到 B1 后能否落验？（已落验 / 只落承接 / 未落验）

### 5.3 归层（六选一）
- 终局利成 / 终局利空 / 过程助成 / 过程阻滞 / 条件性待实 / 高危救应未断附记

固定拦句：
- 药到病不等于药落验。
- 医护接入不是医护救回。

## F6 裁决

### 非安危（F6b）
- 结论：成 / 不成（唯一）
- 概率档：高 / 中高 / 中 / 不足
- 过程语：顺成/卡成/补后成/迟成/卡败/拖败
- 病药摘要：B1、Y1、Y1到B1、Y1落验
- 反向证明：成法落点或不成卡点

### 安危（F6a）
- 用神状态档：用神显形 / 用神可确认 / 用神得救 / 用神绝断
- 安全层：平安倾向 / 安全未确认 / 高危不安全
- 死亡终态象层：死亡终态象强 / 死亡终态象未坐实 / 未触发
- 附记：高危救应未断 / 重危有药候选 / 鬼门关格候选 / 未触发
- 概率档 + 过程语 + 病药摘要

**现实处置旁注（固定保留）**：
以下只作卦象结构解读，不构成现实安全、死亡、医疗或救援判断。现实上仍应同步联系警方、医院、家属、现场救援或专业机构核实。

- 应期精度：EP0/EP1/EP2/EP3

- 触发点/承接点/落地点
- 白话候选稿（一句话）
- 外放状态：可外放 / 不可外放

- 自检简码（F0-F7 + 安危红线 + 过程证/终局证 + 白话外放门 + L5状态）

> 安危类且“安全未确认/高危不安全/死亡终态象未坐实/高危救应未断”时，默认 EP0 或 EP1。
